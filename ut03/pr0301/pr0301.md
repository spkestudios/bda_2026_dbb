## 2. Selección de las playas

`Identifica` es un código interno del MITECO. Para encontrar las playas de AEMET uso `Código_IN` e `ID_MUNICIPIO`, que identifican el mismo municipio. Un municipio puede tener varias playas. Ordeno por `ID_PLAYA` y me quedo con las primeras 15 para repetir siempre la misma selección.

```python
provincia = config.PROVINCIA
en_provincia = miteco["Provincia"].str.strip().str.casefold() == provincia.strip().casefold()
municipios = miteco.loc[en_provincia, "Código_IN"].dropna().str.strip().str.zfill(5).unique()

en_municipios = aemet["ID_MUNICIPIO"].str.strip().str.zfill(5).isin(municipios)
candidatas = aemet.loc[en_municipios].copy()
candidatas["ID_PLAYA"] = candidatas["ID_PLAYA"].str.strip().str.zfill(7)
candidatas = candidatas.loc[candidatas["ID_PLAYA"].str.fullmatch(r"[0-9]{7}", na=False)]
candidatas = candidatas.drop_duplicates("ID_PLAYA").sort_values("ID_PLAYA")
seleccion = candidatas.head(config.MAX_PLAYAS)

print(f"{provincia}: {en_provincia.sum()} playas del MITECO en {len(municipios)} municipios")
print(f"Playas con código AEMET: {len(candidatas)}. Seleccionadas: {len(seleccion)}.\n")
print(seleccion[["ID_PLAYA", "NOMBRE_PLAYA", "NOMBRE_MUNICIPIO"]].to_string(index=False))
```

## 4. Subida de prueba a Amazon S3

Subo los dos CSV desde disco con `upload_file`. Si AEMET ha devuelto la predicción, la subo desde memoria con `put_object`. Leo los metadatos con `head_object` para comprobar el origen y la fecha de cada objeto.

Los catálogos van en dos carpetas `v1` porque cada proveedor puede actualizar su fichero por separado. Las predicciones van en carpetas de año, mes y día. Así se puede leer una fecha concreta sin recorrer los demás días.

```python
from importlib.util import find_spec

if config.faltan_claves_aws():
    print("Subida pendiente. Faltan las credenciales de AWS en .env.")
elif find_spec("boto3") is None:
    print("Subida pendiente. Falta instalar boto3 en este intérprete de Python.")
else:
    from s3_manager import conectar_s3, subir_archivo, subir_prediccion

    s3 = conectar_s3()
    claves = [
        subir_archivo(s3, config.CSV_MITECO, config.CLAVE_MITECO, "MITECO_OpenData"),
        subir_archivo(s3, config.CSV_AEMET, config.CLAVE_AEMET, "AEMET_Catalogo"),
    ]
    if prediccion is not None:
        claves.append(subir_prediccion(s3, id_prueba, prediccion))
    else:
        print("Subida del JSON pendiente. Hace falta una predicción válida.")

    for clave in claves:
        objeto = s3.head_object(Bucket=config.BUCKET, Key=clave)
        print(f"s3://{config.BUCKET}/{clave}")
        print(objeto["Metadata"])
```
