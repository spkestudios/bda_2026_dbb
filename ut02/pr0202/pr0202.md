# PR0202. Uso del cliente HDFS

**Alumno: Diego Blanco Barredo**

He realizado los ocho ejercicios en el clúster de Hadoop de Docker. Dentro del contenedor trabajo como `root`, por eso mi carpeta personal es `/user/root`. Los comandos de HDFS se ejecutan dentro de `namenode` y los comandos `docker cp`, desde PowerShell.

He utilizado el fichero `vehicle_price_prediction.csv` del [dataset de coches indicado en la actividad](https://www.kaggle.com/datasets/metawave/vehicle-price-prediction).

## 1. Preparación del entorno

Creé la carpeta `proyecto_datos` dentro de mi espacio personal y comprobé que existía.

```bash
hdfs dfs -mkdir -p /user/root/proyecto_datos
hdfs dfs -ls -d /user/root/proyecto_datos
```

Salida:

```text
drwxr-xr-x   - root supergroup          0 2026-10-27 12:16 /user/root/proyecto_datos
```

## 2. Carga del dataset

El script descargó el CSV de Kaggle a mi PC. Después lo copié al contenedor y lo subí a HDFS.

Desde PowerShell:

```powershell
docker cp C:\Users\diego\AppData\Local\Temp\bda_pr0202_diego\vehicle_price_prediction.csv namenode:/tmp/pr0202_20261027_131642_6fdc2e/vehicle_price_prediction.csv
```

Dentro del contenedor:

```bash
hdfs dfs -put /tmp/pr0202_20261027_131642_6fdc2e/vehicle_price_prediction.csv /user/root/proyecto_datos/vehicle_price_prediction.csv
hdfs dfs -ls /user/root/proyecto_datos/vehicle_price_prediction.csv
```

Salida:

```text
-rw-r--r--   3 root supergroup  126967327 2026-10-27 12:17 /user/root/proyecto_datos/vehicle_price_prediction.csv
```

El fichero se subió correctamente y ocupa **126.967.327 bytes**.

## 4. Organización del proyecto

Creé las carpetas `backup` y `procesados`. Copié el fichero a `backup` y moví el original a `procesados`.

```bash
hdfs dfs -mkdir -p /user/root/proyecto_datos/procesados /user/root/proyecto_datos/backup
hdfs dfs -cp /user/root/proyecto_datos/vehicle_price_prediction.csv /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
hdfs dfs -mv /user/root/proyecto_datos/vehicle_price_prediction.csv /user/root/proyecto_datos/procesados/vehicle_price_prediction.csv
hdfs dfs -ls /user/root/proyecto_datos/backup/vehicle_price_prediction.csv /user/root/proyecto_datos/procesados/vehicle_price_prediction.csv
hdfs dfs -ls /user/root/proyecto_datos
```

Salida de las comprobaciones:

```text
-rw-r--r--   3 root supergroup  126967327 2026-10-27 12:17 /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
-rw-r--r--   3 root supergroup  126967327 2026-10-27 12:17 /user/root/proyecto_datos/procesados/vehicle_price_prediction.csv
Found 2 items
drwxr-xr-x   - root supergroup          0 2026-10-27 12:17 /user/root/proyecto_datos/backup
drwxr-xr-x   - root supergroup          0 2026-10-27 12:17 /user/root/proyecto_datos/procesados
```

## 5. Colaboración en el equipo

Creé una carpeta dentro de `/compartido` y copié allí el dataset. Dejé el fichero con permisos `644`, para que otros usuarios puedan leerlo. También comprobé que las carpetas permiten el acceso.

```bash
hdfs dfs -mkdir -p /compartido/root/proyecto_datos
hdfs dfs -cp /user/root/proyecto_datos/procesados/vehicle_price_prediction.csv /compartido/root/proyecto_datos/vehicle_price_prediction.csv
hdfs dfs -chmod 644 /compartido/root/proyecto_datos/vehicle_price_prediction.csv
hdfs dfs -ls -d /compartido /compartido/root /compartido/root/proyecto_datos
hdfs dfs -ls /compartido/root/proyecto_datos/vehicle_price_prediction.csv
```

Salida de las comprobaciones:

```text
drwxr-xr-x   - root supergroup          0 2026-10-27 12:17 /compartido
drwxr-xr-x   - root supergroup          0 2026-10-27 12:17 /compartido/root
drwxr-xr-x   - root supergroup          0 2026-10-27 12:17 /compartido/root/proyecto_datos
```

## 7. Control de accesos

Revisé los permisos del backup y los cambié a `600`. Así, solo el propietario tiene permisos de lectura y escritura.

```bash
hdfs dfs -ls /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
hdfs dfs -chmod 600 /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
hdfs dfs -ls /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
```

Antes del cambio:

```text
-rw-r--r--   3 root supergroup  126967327 2026-10-27 12:17 /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
```

Después del cambio:

```text
-rw-------   3 root supergroup  126967327 2026-10-27 12:17 /user/root/proyecto_datos/backup/vehicle_price_prediction.csv
```
