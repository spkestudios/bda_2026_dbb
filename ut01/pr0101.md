# PR0101. Preparación del repositorio

## Objetivo

Preparar un repositorio para organizar y entregar las prácticas
del módulo de Big Data Aplicado.

## Organización

El repositorio está organizado por unidades de trabajo.
Cada unidad tiene un índice y cada práctica dispone de su propia carpeta.

Los documentos están escritos en Markdown y contienen enlaces
para navegar entre los distintos niveles.
